# AHbsolute — неофициальный клиент на базе Telegram for Android

Этот репозиторий **не содержит весь код Telegram**. Он содержит только наши изменения
(папка `overlay/` и скрипты патчей). При сборке GitHub Actions сам скачивает свежий
исходный код из https://github.com/TelegramMessenger/Telegram-Android, накладывает на него
изменения AHbsolute и собирает APK.

## Как собрать (5 шагов)

1. Создайте на GitHub **публичный** репозиторий и загрузите в него содержимое этого архива.
2. Получите **свои** `api_id` и `api_hash` на https://my.telegram.org → *API development tools*.
3. Репозиторий → *Settings → Secrets and variables → Actions → New repository secret*:
   * `TG_API_ID` — число
   * `TG_API_HASH` — строка
   * (необязательно) `GOOGLE_SERVICES_JSON` — ваш файл Firebase, чтобы работали push через FCM
   * (необязательно) `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` — ваш ключ подписи
4. Вкладка *Actions* → **Build AHbsolute** → *Run workflow*.
5. Через ~40–90 минут APK будет в *Artifacts* → `AHbsolute-apk`.

Без `TG_API_ID`/`TG_API_HASH` сборка намеренно остановится: использовать идентификатор
официального приложения нельзя.

## Что внутри

| Функция | Как работает |
|---|---|
| **Изменение интерфейса** | Боковое меню → **AHbsolute** → «Изменение интерфейса». Кнопки главного экрана (пункты бокового меню) переставляются стрелками ▲▼, есть «Сбросить порядок». Чаты не затрагиваются. |
| **Формы аватара** | Круг, Квадрат, Звезда, Треугольник. Выбор в AHbsolute → «Форма аватара». Своя форма видна вам сразу; другие пользователи AHbsolute увидят её, если включить «Показывать мою форму…». |
| **Иконка** | Ваша фиолетовая иконка заменяет все иконки запуска (`scripts/make_icons.py`). Логотип Telegram не используется. |
| **Оптимизация** | см. ниже |

### Как работает «видно только пользователям AHbsolute»
У Telegram нет поля для таких данных, поэтому при включённой опции к **вашей фамилии
добавляется невидимый маркер** (символы нулевой ширины). Обычные клиенты показывают
круглый аватар и ту же фамилию; AHbsolute распознаёт маркер и рисует нужную форму.
Опция **выключена по умолчанию**, при выключении маркер удаляется.
Честные оговорки: маркер технически остаётся частью имени; сервер Telegram теоретически
может такие символы обрезать — тогда форма будет видна только вам.

### Оптимизации
* Сборка только под `arm64-v8a` и `armeabi-v7a` (без x86): APK заметно меньше, сборка быстрее.
* Кэш путей форм и нулевая нагрузка для обычных (круглых) аватаров: хук рисует форму только когда она выбрана.
* Необязательная (по умолчанию выключена) фоновая очистка кэша старше 30 дней при запуске.
* Остальное — стандартные «Энергосбережение» и «Использование памяти» самого клиента.

## Законность: чек-лист (Telegram API Terms of Service + лицензия)

* ✅ Свой `api_id` (п. 2.1) — сборка без него не запускается.
* ✅ Название **AHbsolute** не содержит слова «Telegram» (п. 2.3); экран AHbsolute прямо пишет, что клиент неофициальный и использует Telegram API.
* ✅ Логотип Telegram не используется (п. 2.4) — иконки заменяются, скрипт предупреждает, если находит похожие файлы.
* ✅ Спонсорские сообщения в каналах не отключены (п. 3.3) — этот код мы не трогаем. **Не удаляйте их.**
* ✅ Другие клиенты ничего не теряют: аватар и имя видны всем (п. 1, запрет «заставлять скачивать ваше приложение»).
* ✅ Лицензия GPL-2.0: держите репозиторий публичным, добавьте файл `LICENSE` (см. `NOTICE.md`) и публикуйте исходники вместе с APK.
## Важно:

* Первый запуск может упасть на шаге **Apply patches** (скрипт скажет, какой якорь не найден)
  или на компиляции. Скопируйте лог ошибки — поправлю.
* Пункт «AHbsolute» добавлен в **боковое меню**, а не внутрь стандартного списка «Настройки»:
  экран настроек Telegram очень большой, и править его вслепую рискованно.
* «Кнопки главного экрана» я понял как пункты бокового меню. Если вы имели в виду другое
  (например, плавающую кнопку или вкладки папок) — скажите.
* Собирается задача `:TMessagesProj_App:assembleAfatRelease` (так указано в документации Telegram по воспроизводимым сборкам).

## Автоматический запасной вариант (чтобы была зелёная галочка)

Сборка идёт до трёх попыток и сама выбирает первую удавшуюся:

1. **full** — все функции, только arm64 и armv7.
2. **full-allabi** — все функции, все архитектуры (если проблема была в фильтре ABI).
3. **safe** — только название, ваш `api_id`, пакет и иконка; меню-редактор и формы аватара отключены.

Какая версия получилась, написано в сводке запуска (*Summary*) и в имени артефакта:
`AHbsolute-apk-full`, `AHbsolute-apk-full-allabi` или `AHbsolute-apk-safe`.
Если получилась `safe`, откройте лог первой попытки (артефакт `build-log`), найдите первую
строку `error:` или `FAIL:`.
