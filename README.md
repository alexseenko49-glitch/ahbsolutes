# AHbsolute — неофициальный клиент на базе Telegram for Android

Этот репозиторий **не содержит весь код Telegram**. Он содержит только наши изменения
(папка `overlay/` и скрипты патчей). При сборке GitHub Actions сам скачивает свежий
исходный код из https://github.com/TelegramMessenger/Telegram-Android, накладывает на него
изменения AHbsolute и собирает APK.

## Как собрать (5 шагов)

1. Создайте на GitHub **публичный** репозиторий и загрузите в него содержимое этого архива.
2. Получите **свои** `api_id` и `api_hash` на https://my.telegram.org → *API development tools*.
3. Репозиторий → *Settings → Secrets and variables → Actions → New repository secret*:
   * `TG_API_ID` — число
   * `TG_API_HASH` — строка
   * (необязательно) `GOOGLE_SERVICES_JSON` — ваш файл Firebase, чтобы работали push через FCM
   * (необязательно) `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` — ваш ключ подписи
4. Вкладка *Actions* → **Build AHbsolute** → *Run workflow*.
5. Через ~40–90 минут APK будет в *Artifacts* → `AHbsolute-apk`.

Без `TG_API_ID`/`TG_API_HASH` сборка намеренно остановится: использовать идентификатор
официального приложения нельзя.

## Что внутри

| Функция | Как работает |
|---|---|
| **Absolute Design 1** | Один переключатель вверху экрана AHbsolute. Включает фирменную тему (светлую или ночную — по текущей теме Telegram) с собственными обоями, стеклянный профиль, баннер, стеклянную панель, компактную верхнюю панель и анимации. Все функции Telegram и AHbsolute остаются на своих местах. Выключение возвращает всё, как было до включения. |
| **Главный экран** | Вместо логотипа Telegram в верхней панели — надпись **AHbsolute** (в Design 1 — с фирменным градиентом). *AHbsolute → Главный экран*: расстояние между чатами, чаты карточками, скругление карточек, обои за чатами — тогда карточки стеклянные. |
| **Кастомизация верхней панели** | *AHbsolute → Кастомизация*: компактная верхняя панель (надпись AHbsolute, поиск, меню) в скруглённой капсуле; размер панели, скругление краёв (до «капсулы») и отступы по краям. С обоями за чатами капсула стеклянная, а шапка при прокрутке показывает те же обои, не темнея. |
| **Падающие буквы** | Стёртые буквы выпрыгивают из поля ввода, падают на сообщения (или на чат), отскакивают и исчезают за 2 секунды. *AHbsolute → Сообщения → Падающие буквы при удалении* (можно выключить). |
| **Быстрый просмотр** | Два быстрых нажатия на чат: он открывается из точки, а через мгновение красиво сворачивается обратно в ту же точку. |
| **Профиль для пользователей AHbsolute** | *AHbsolute → Видно пользователям AHbsolute*: ваш баннер, обои, стекло и репосты постов увидят другие пользователи AHbsolute в вашем профиле. Работает через ваш **личный канал** Telegram: AHbsolute публикует туда пост «Мой профиль в AHbsolute» (данные спрятаны в ссылке на проект) и ваши картинки. В обычном Telegram это просто посты канала. |
| **Репосты сообщений** | «Репост» есть и у обычных сообщений. Репосты постов из каналов видят пользователи AHbsolute (если включено), репосты сообщений (🔒) — никто, кроме вас. |
| **Экстремальное удаление** | Нажмите на своё сообщение → «Экстремальное удаление»: без вопросов удаляется у всех на сервере и из памяти телефона, в чате не остаётся даже следа. Скриншоты, уже показанные уведомления, приложения, которые сами копируют сообщения, и боты Telegram Business у собеседника (получают копию в момент отправки и видят удаление) обойти не может никакой клиент. |
| **Перемещение чатов** | Зажмите чат (он выделится), зажмите ещё раз и тяните вверх или вниз: он останется на новом месте (хранится на телефоне). Сброс — *AHbsolute → Главный экран*. |
| **Перенос настроек** | «Скопировать настройки» кладёт в буфер число со всеми настройками; «Ввод настроек» возвращает всё как было (на этом или другом телефоне). Свои картинки из галереи в число не входят. |
| **Absolute Design 2 «Aurora»** | Второй фирменный дизайн: мятно-бирюзовая тема с северным сиянием (светлая и ночная), капсула-панель, крупные стеклянные карточки, аватар слева и имя рядом, Liquid Glass и падающие буквы. Design 1 и Design 2 переключаются в AHbsolute; выключение возвращает всё как было. |
| **Встряхнуть — сменить дизайн** | Своя фишка AHbsolute (по умолчанию выключена): три резких встряхивания переключают Design 1 → Design 2 → обычный вид. |

| **Пасхалка** | Два быстрых нажатия на «Диагностика» — экран с иконкой AHbsolute и версией (**v1.02**). Выход — стрелкой в левом верхнем углу. |

| **Кастомизация профиля** | Аватар слева / по центру / справа (имя и «в сети» по умолчанию идут вместе с аватаром; при аватаре сбоку они встают рядом с ним, а всё ниже поднимается вверх), размер аватара (80–130%), выравнивание и размер имени, прозрачность шапки, только мой профиль или все. Вверху экрана настроек — живой предпросмотр. |
| **Репосты** | Зажмите пост в канале → **Репост**. В вашем профиле появляется строка **Репосты** с количеством; там список постов, нажатие открывает оригинальный пост в канале, удержание — убирает репост. |
| **Свои баннеры профиля** | Иконка **AHbsolute ⚙** (или *Настройки → AHbsolute*) → «Загрузить баннер из галереи». Можно загрузить сколько угодно картинок, выбрать любую, удалить долгим нажатием. Настраиваются яркость, затемнение, затухание книзу, положение картинки, прозрачность шапки и где показывать (только мой профиль / все профили). Вверху экрана — живой предпросмотр. |
| **Интерфейс как у Telegram** | Экран AHbsolute собран из родных ячеек Telegram (заголовки секций, переключатели, радиокнопки, серые подсказки, диалоги выбора) и берёт цвета из текущей темы, в т.ч. тёмной. Пункт **AHbsolute** стоит в обычных *Настройках* сразу после «Язык», с такой же цветной иконкой, как у остальных пунктов. |
| **Формы аватара** | Круг, Квадрат, Звезда, Треугольник. Своя форма видна вам сразу; другие пользователи AHbsolute увидят её, если включить «Показывать форму…». |
| **Оформление** | Стеклянная панель, обои по теме, анимации, размытие при прокрутке и т.д. — каждый эффект отдельным переключателем; главный выключатель возвращает обычный вид Telegram. |
| **Темы AHbsolute** | Vice, Chess, Absolut, Teg или стандартная тема Telegram. |
| **Иконка** | Ваша фиолетовая иконка заменяет все иконки запуска (`scripts/make_icons.py`). Логотип Telegram не используется. |

### Исправлено: APK с `testOnly`
Раньше сборка передавала Gradle параметр `-Pandroid.injected.build.abi=…`. Android Gradle Plugin считает такую
сборку «сборкой из Android Studio» и помечает APK `android:testOnly="true"` — телефон такой APK не ставит
(`INSTALL_FAILED_TEST_ONLY`). Теперь:
* ABI ограничиваются прямо в `build.gradle` (arm64-v8a + armeabi-v7a), без `injected`-параметра;
* в `gradle.properties` и в команду Gradle добавлено `android.injected.testOnly=false`;
* любые `testOnly="true"` / `testOnly true` в манифестах и gradle-файлах заменяются на `false`;
* после сборки скрипт проверяет готовый APK через `aapt2` и падает с ошибкой, если флаг всё-таки `true`.

### Как работает «видно только пользователям AHbsolute»
У Telegram нет поля для таких данных, поэтому при включённой опции к **вашей фамилии
добавляется невидимый маркер** (символы нулевой ширины). Обычные клиенты показывают
круглый аватар и ту же фамилию; AHbsolute распознаёт маркер и рисует нужную форму.
Опция **выключена по умолчанию**, при выключении маркер удаляется.
Честные оговорки: маркер технически остаётся частью имени; сервер Telegram теоретически
может такие символы обрезать — тогда форма будет видна только вам.

### Оптимизации
* Сборка только под `arm64-v8a` и `armeabi-v7a` (без x86): APK заметно меньше, сборка быстрее.
* Кэш путей форм и нулевая нагрузка для обычных (круглых) аватаров: хук рисует форму только когда она выбрана.
* Необязательная (по умолчанию выключена) фоновая очистка кэша старше 30 дней при запуске.
* Остальное — стандартные «Энергосбережение» и «Использование памяти» самого клиента.

## Законность: чек-лист (Telegram API Terms of Service + лицензия)

* ✅ Свой `api_id` (п. 2.1) — сборка без него не запускается.
* ✅ Название **AHbsolute** не содержит слова «Telegram» (п. 2.3); экран AHbsolute прямо пишет, что клиент неофициальный и использует Telegram API.
* ✅ Логотип Telegram не используется (п. 2.4) — иконки заменяются, скрипт предупреждает, если находит похожие файлы.
* ✅ Спонсорские сообщения в каналах не отключены (п. 3.3) — этот код мы не трогаем. **Не удаляйте их.**
* ✅ Другие клиенты ничего не теряют: аватар и имя видны всем (п. 1, запрет «заставлять скачивать ваше приложение»).
* ✅ Лицензия GPL-2.0: держите репозиторий публичным, добавьте файл `LICENSE` (см. `NOTICE.md`) и публикуйте исходники вместе с APK.
* ⚠️ Если будете раздавать APK другим людям — прочитайте https://core.telegram.org/api/terms целиком (условия могут меняться) и учтите политику вашего магазина приложений.
* Строки интерфейса вида «Telegram Premium», «Telegram FAQ» остаются: это названия сервиса, а не название приложения.

## Важно: что я не мог проверить

Сайт GitHub закрыт для автоматического чтения, а в моей среде нет интернета, поэтому
**исходный код Telegram-Android я не видел** и ничего не компилировал. Патчи написаны по
моему знанию структуры проекта и проверены только на макете. Поэтому:

* Первый запуск может упасть на шаге **Apply patches** (скрипт скажет, какой якорь не найден)
  или на компиляции. Скопируйте лог ошибки — поправлю.
* В текущем Telegram-Android больше нет бокового меню (`DrawerLayoutAdapter`), поэтому функция «menu»
  пропускается, а вход в AHbsolute — через *Настройки → AHbsolute* и иконку **AHbsolute ⚙**.
* Баннер, обои, стекло, раскладка профиля и репосты локальные: в Telegram нет полей, через которые их можно передать другим, поэтому их видите только вы.
* Собирается задача `:TMessagesProj_App:assembleAfatRelease` (так указано в документации Telegram по воспроизводимым сборкам).

## Автоматический запасной вариант (чтобы была зелёная галочка)

Сборка делает несколько попыток и сама выбирает первую удавшуюся:

Сначала собираются все функции, затем по очереди отключаются самые рискованные (anim/edit, streak/blur, splash, title…).
Баннеры профиля (`profile`) и пункт в Настройках (`settings`) остаются до последних попыток.

Какая версия получилась, написано в сводке запуска (*Summary*) и в имени артефакта:
например `AHbsolute-apk-anim-avatar-blur-edit-profile-settings-...`.
Если какой-то функции не хватает, откройте лог (артефакт `build-log`), найдите первую
строку `error:` или `FAIL:` и пришлите её — я включу функцию обратно.

Красный крест возможен только если не собралась ни одна попытка: нет секретов `TG_API_ID`/`TG_API_HASH`,
GitHub не смог скачать SDK/NDK, закончилось место или время (лимит 6 часов), либо в Telegram-Android
изменилась сама система сборки. Тогда пришлите последние 50 строк лога.
